Set up in four steps

1

Run Bambuddy

Self-host Bambuddy on your own hardware — it's already your command center.

2

Grab an API key

Settings → API Keys in Bambuddy. Scope it to Read Status and Manage Inventory.

3

Add it in NozzleCast

Paste your server URL and key. Both stay in the Keychain — never in plain files.

4

Manage from anywhere

Monitor, control, and restock filament — no account, no middleman server.

Optional: push notifications & Live Activities need two more pieces

Monitoring and filament scanning work with just your Bambuddy server. Push notifications additionally need your own Firebase project — import its GoogleService-Info.plist in Settings to receive Bambuddy's ntfy alerts in-app. Lock Screen Live Activities need one more piece on top: nozzlecast-relay, a small open-source service you self-host next to Bambuddy to forward print events to Apple's push service. No NozzleCast-operated server is involved in either.

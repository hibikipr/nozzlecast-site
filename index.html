Set up in four steps

1

Run Bambuddy

Self-host Bambuddy on your own hardware — it's already your command center.

2

Grab an API key

Settings → API Keys in Bambuddy. Scope it to Read Status and Manage Inventory.

3

Add it in NozzleCast

Paste your server URL and key. Both stay in the Keychain — never in plain files.

4

Manage from anywhere

Monitor, control, and restock filament — no account, no middleman server.

Optional: instant push & locked-phone Live Activities

Everything works with just your Bambuddy server. Alerts are read from Bambuddy's notification log, so they can arrive a little late, and Live Activities start and update while the app is open. For instant push, and Live Activities that start the moment a print begins — even with your phone locked — you build NozzleCast yourself with your own Apple Developer account, then add your own Firebase project and nozzlecast-relay, a small open-source service you self-host next to Bambuddy. Apple only lets the developer account that signs an app send it pushes, which is why this can't work with the App Store build. No NozzleCast-operated server is involved either way.
